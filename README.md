CELESTE GOLD

A jewelry e-commerce platform with a customer storefront and an admin dashboard.


Tech Stack

Frontend: React 19 + Vite
Backend: Express, Sequelize, MySQL
Auth: JWT with refresh tokens


Features

Product browsing, search, filtering, favorites, pagination, and customization/engraving
Discounts (percentage or flat amount, with scheduled dates)
Cart and checkout (Stripe)
Admin dashboard: Employees, Customers, Products, Categories, Suppliers, Payments, Orders, Contacts, Reviews, Work Schedules, Reminders, Discounts
Role-based access control (RBAC)
Audit logs, low-stock alerts, personalized, and work schedule alerts
